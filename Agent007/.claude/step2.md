# используем tkinter для создания окон, кнопок, полей ввода и других элементов интерфейса.

# каждая кнопка/окно/панель должны быть отдельными файлами и легко подключаемыми к основному приложению.
# для кадого окна/панели создаем отдельный класс, который будет отвечать за его функциональность и взаимодействие с другими частями приложения.
