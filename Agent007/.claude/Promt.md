## ОПИСАНИЕ ПРОЕКТА 
# Полноэкранное приложение по управлению телеграм аккаунтами, подключение к API Telegram, управление чатами и сообщениями, автоматизация задач, интеграция с базой данных для хранения информации о пользователях и чатах, поддержка нескольких аккаунтов, возможность отправки сообщений и медиафайлов, настройка уведомлений и фильтров, аналитика активности пользователей и чатов.
# Используется язык программирования: Python
# Используется база данных: MySQL
# Исползуется поддержка очередей задач: Kafka
# 
## ОСНОВНЫЕ ТРЕБОВАНИЯ
# соблюдение правил SOLID, DRY, KISS, YAGNI, использование паттернов проектирования, модульное тестирование, логирование и обработка ошибок, поддержка многопоточности и асинхронного программирования, использование виртуальных окружений и контейнеризации (Docker), настройка CI/CD процессов.
# каждое изменение прогоняется через тестирование, написание документации и комментариев к коду, соблюдение стандартов кодирования (PEP8), использование инструментов для статического анализа кода (например, pylint, flake8), настройка мониторинга и алертинга для отслеживания состояния приложения.
# логирование ошибок записывается в отдельный файл в ./Log дериктории

## ТРЕБОВАНИЯ К РАЗРАБОТКЕ
